# CastOrbit — frontend

React + Vite playback UI for `out/batch.json` and `out/sweeps.json`. Per
[`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) §2: **this app never
simulates anything.** Every number on screen is read from those two files;
nothing physical is computed in the browser. If a view needs a value the JSON
doesn't carry, add it to the Python export (`sim/export.py`, `sim/sweeps.py`)
and regenerate — see [`sim/groundtrack.py`](../sim/groundtrack.py) for the one
partial exception (globe marker position is display geometry, not physics,
and says so).

## Run it

```bash
# from the repo root, with the Python env set up (see the main README)
.venv/bin/python -m sim.export    # writes out/batch.json
.venv/bin/python -m sim.sweeps    # writes out/sweeps.json

cd web
npm install
npm run dev                       # syncs out/*.json into public/data/ first
```

`npm run build` / `npm run preview` work the same way — both run
`sync-data` (see `scripts/sync-data.mjs`) before touching Vite, so the app
never ships stale data relative to whatever's in `out/`.

## Views

| View | Reads | Notes |
|---|---|---|
| Globe | `batch.json` | Forces an explicit Cd = 2.2 / Cd = 1.0 choice before rendering anything — see the hard rule below. |
| Altitude | `batch.json` | Both runs always shown side by side. |
| Sweeps | `sweeps.json` | Three tabs: insertion altitude, ram area, safe-mode timing. |
| Validation | `sweeps.json` (`.validation`) + `batch.json` (`.observed`, `.runs`) | The Baruah comparison table. |

**batch.json carries two Cd conventions and the UI must never default to one
silently.** The Globe view starts with neither selected and shows both
outcome-count summaries before any satellite renders. The Altitude view
sidesteps the question entirely by always rendering both panels.

## Structure

```
src/
  context/    DataContext (fetches both JSON files once), PlaybackContext
              (the shared scrubber + UT clock, ARCHITECTURE.md §7)
  lib/        display-only helpers -- formatting, trajectory interpolation,
              recharts row-shaping. No physics; see each file's docstring.
  components/ Scrubber, OutcomeLegend, RunSelector, NavTabs
  views/      GlobeView, AltitudeView, SweepsView, ValidationView
```

`public/textures/earth-dark.jpg` is bundled from `three-globe` (MIT), the
library's own example asset for `react-globe.gl`'s `globeImageUrl`.
`public/data/` is gitignored and regenerated by `sync-data`, same as `out/`
at the repo root.
